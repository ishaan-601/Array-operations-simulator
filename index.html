7 Algorithms

Selection Sort

O(N²) O(1)

Finds the minimum element from the unsorted portion and places it at the beginning. Repeats for each position.

// Algorithm
for i = 0 to N‑1:
  minIdx = i
  for j = i+1 to N:
    if A[j] < A[minIdx]: minIdx = j
  swap(A[i], A[minIdx])

Bubble Sort

O(N²) O(1)

Repeatedly swaps adjacent elements if they are out of order. Largest element "bubbles" to the end each pass.

// Algorithm
repeat:
  swapped = false
  for i = 1 to N:
    if A[i‑1] > A[i]:
      swap; swapped = true
until !swapped

Insertion Sort

O(N²) O(1)

Builds the sorted array one element at a time by inserting each new element into its correct position.

// Algorithm
for i = 1 to N:
  key = A[i]; j = i‑1
  while j≥0 and A[j]>key:
    A[j+1] = A[j]; j‑‑
  A[j+1] = key

Quick Sort

O(N log N) O(log N)

Divide‑and‑conquer: picks a pivot, partitions the array around it, then recursively sorts each partition.

// Algorithm
quickSort(lo, hi):
  pivot = A[hi]
  partition around pivot
  quickSort(lo, p‑1)
  quickSort(p+1, hi)

Merge Sort

O(N log N) O(N)

Recursively splits the array in half, sorts each half, then merges them back in sorted order. Stable sort.

// Algorithm
mergeSort(arr):
  if len≤1: return
  mid = len/2
  L = mergeSort(left half)
  R = mergeSort(right half)
  merge(L, R)

Shell Sort

O(N log N) O(1)

Generalised insertion sort that compares elements far apart first, reducing the gap each pass until gap = 1.

// Algorithm
gap = N/2
while gap > 0:
  insertion sort with gap
  gap = gap/2

Radix Sort

O(N·k) O(N+k)

Non-comparative sort. Sorts digits from least‑significant to most‑significant using counting sort as a sub‑routine.

// Algorithm
for each digit place:
  countingSort(arr, place)
(LSD: 1s → 10s → 100s)
